SE.LLMA — Weight-Space Programming

This project investigates whether learned Swedish-language characteristics can be identified directly from neural network weights, inspired by the research Sparks of Weight-Space Programming.

The experiment uses small BERT models trained on English and Swedish datasets with the same architecture to examine whether weight-space analysis can distinguish language-specific learning.

Repository Contents

This repository contains only the Jupyter Notebook used for the experiments.

The model files and trained weights are not included due to their large file sizes.
